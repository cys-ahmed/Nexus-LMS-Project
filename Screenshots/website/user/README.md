# User UI Screenshots

Screenshots of the Nexus LMS student-facing interface, capturing all major student panel views and features.

---

## Overview

This directory contains visual records of the student-facing pages of the Nexus LMS platform. These screenshots document the student dashboard, course catalog, course content, profile management, and certificate views as rendered in a web browser.

---

## Files

| File                 | Description                                                                                           |
|----------------------|-------------------------------------------------------------------------------------------------------|
| `Dashboard.png`      | The student dashboard page displaying enrolled course progress cards, active announcements, and learning statistics. |
| `Course_Catalog.png` | The student course catalog page showing available courses as browsable cards with thumbnails, pricing, and enrollment actions. |
| `Course_Content.png` | The student course detail/content page showing course description, instructor information, progress tracking, and reviews. |
| `Profile.png`        | The student profile management page with username, email, role display, and account update forms.     |
| `Certificates.png`   | The student certificates page displaying earned completion certificates for courses with 100% progress. |
