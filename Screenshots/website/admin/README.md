# Admin UI Screenshots

Screenshots of the Nexus LMS administrative interface, capturing all major admin panel views and management features.

---

## Overview

This directory contains visual records of the administrator-facing pages of the Nexus LMS platform. These screenshots document the admin dashboard, user management, course management, announcement management, and settings views as rendered in a web browser.

---

## Files

| File                                | Description                                                                                     |
|-------------------------------------|-------------------------------------------------------------------------------------------------|
| `Dashboard.png`                     | The admin dashboard page displaying platform-wide statistics (student count, course metrics, enrollments, revenue). |
| `Admin_Panel.png`                   | The primary admin panel view showing the main administrative layout with sidebar navigation.    |
| `Admin_Panel_User_Management.png`   | The user management section of the admin panel, displaying the user table with role assignments and action controls. |
| `Admin_Panel_Course_Management.png` | The course management section showing the course listing with status indicators and management actions. |
| `Admin_Panel_Announcements.png`     | The announcements management section showing existing announcements and the creation interface. |
| `Admin_Panel_Setting.png`           | The admin settings panel with configuration options and administrative controls.                |
| `Course_Management.png`             | Detailed course catalog management view with full course listings, metadata, and batch operations. |
| `Edit_Course.png`                   | The course editing interface showing the form for modifying course details (title, description, instructor, price, level, status). |
