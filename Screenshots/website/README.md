# Website Screenshots

Screenshots of the Nexus LMS web application user interface, organized by user role.

---

## Overview

This directory contains visual records of the Nexus LMS application frontend as rendered in a web browser. Screenshots are organized into role-specific subdirectories (admin and student views) with the shared login page at this level. These images document the application's UI/UX design and are used in project presentations, reports, and academic deliverables.

---

## Directory Contents

### Subdirectories

- **admin/** -- Screenshots of the administrative interface including the dashboard, user management panel, course management views, announcement management, settings, and course editing controls.
- **user/** -- Screenshots of the student-facing interface including the student dashboard, course catalog, course content view, profile page, and certificates display.

### Files

- **Login.png** -- Screenshot of the Nexus LMS login page, the shared authentication entry point for all users regardless of role.
