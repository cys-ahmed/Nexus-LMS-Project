# Git Screenshots

Screenshots capturing Git version control workflows, commit history, and repository structure for the Nexus LMS project.

---

## Overview

This directory contains visual records of the Git repository state, documenting the project's version control practices, commit timeline, and directory organization. These screenshots are used in project documentation and academic deliverables to demonstrate proper source control management.

---

## Files

| File                             | Description                                                                                  |
|----------------------------------|----------------------------------------------------------------------------------------------|
| `Git.png`                        | Overview of the Git repository, showing the remote origin, branch state, or repository summary. |
| `Git_Commit_History.png`         | Git commit log displaying the chronological history of changes made to the repository.       |
| `Git_Repository_Structure_1.png` | Repository directory structure view -- top-level organization of the project.                 |
| `Git_Repository_Structure_2.png` | Repository directory structure view -- expanded view of application subdirectories.           |
| `Git_Repository_Structure_3.png` | Repository directory structure view -- additional depth showing backend and pages structure.  |
