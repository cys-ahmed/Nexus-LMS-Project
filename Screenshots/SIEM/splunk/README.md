# Splunk Screenshots

Screenshots documenting the Splunk Enterprise server installation, configuration, and operational use for monitoring the Nexus LMS platform.

---

## Overview

This directory contains visual records of the complete Splunk Enterprise deployment process, from initial installation through setup wizard completion to operational use. These screenshots document the SIEM server-side configuration used to receive, index, and analyze logs forwarded from the Nexus LMS application host.
