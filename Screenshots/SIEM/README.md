# SIEM Screenshots

Screenshots documenting SIEM (Security Information and Event Management) platform setup, configuration, and dashboarding for the Nexus LMS project.

---

## Overview

This directory contains visual evidence of the SIEM integration work performed as part of the Nexus LMS security monitoring setup. Screenshots are organized into platform-specific subdirectories covering both the Splunk Enterprise server (for log analysis and dashboarding) and the Splunk Universal Forwarder (for log shipping from the application host).

---

## Directory Contents

### Subdirectories

- **splunk/** -- Screenshots of the Splunk Enterprise installation, setup wizard, login interface, search and reporting functionality, and new report creation. Documents the full Splunk server deployment and configuration process.
- **splunk_forwarder/** -- Screenshots of the Splunk Universal Forwarder installation, setup configuration, data input configuration, and monitor registration. Documents the log shipping agent deployment on the Nexus application host.
