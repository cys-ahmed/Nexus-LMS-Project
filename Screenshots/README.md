# Screenshots

Documentation and evidence directory containing visual records of the Nexus LMS project, organized by topic area.

---

## Overview

This directory serves as the centralized repository for all screenshots, visual evidence, and documentation imagery produced during the development, deployment, security testing, and SIEM integration phases of the Nexus LMS project. Screenshots are organized into topic-specific subdirectories that cover the full lifecycle: server configuration, source code analysis, exploit execution, detection and monitoring, mitigation implementation, SIEM dashboarding, Git workflows, and application UI state.

These assets are used for reports, presentations, proof-of-concept documentation, and academic deliverables.

---

## Directory Contents

### Subdirectories

- **apache/** -- Screenshots documenting Apache web server configuration, virtual host setup, sites-available and sites-enabled states, and document root verification.
- **code/** -- Screenshots of annotated source code used for vulnerability analysis, code review documentation, and highlighted vulnerable code segments.
- **detection/** -- Screenshots demonstrating security detection events, automated scanning tool outputs (Nessus, Nmap, SQLMap), and alert triggers from vulnerability testing.
- **exploits/** -- Visual records of exploit execution and proof-of-concept results from penetration testing, covering SQL injection, XSS, reverse shells, file uploads, and web shells.
- **git/** -- Screenshots capturing Git version control state, commit history, and repository directory structure.
- **mitigation/** -- Screenshots documenting vulnerability remediation steps, security hardening measures, and before/after comparisons of patched code and configuration.
- **SIEM/** -- SIEM-related screenshots organized by platform (Splunk Enterprise and Splunk Universal Forwarder), covering dashboard configuration, log correlation, and forwarder setup.
- **website/** -- Screenshots of the Nexus LMS web application interface, organized by role (admin and student views) with a shared login page screenshot.

### Files

- **SIEM.png** -- High-level SIEM architecture or dashboard overview screenshot.
- **attacker.png** -- Screenshot of the attacker machine environment used during penetration testing exercises.
- **target.png** -- Screenshot of the target machine environment running the Nexus LMS application.
